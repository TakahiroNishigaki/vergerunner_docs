    チャートオブジェクトの描画

    チャート分析において頻繁に使用されると想定したものを採用しています。
    描画をするにはオブジェクトに対応するボタンまたはホットキーを入力後、チャートをクリックするとその位置に描画されます。




    また、時間軸に応じた色を自動的に割り当てており、MTF分析においての視認性が向上します。
