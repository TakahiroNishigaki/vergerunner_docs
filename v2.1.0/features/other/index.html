    チャートテンプレートの保存

    ワンクリックでチャートテンプレートを保存
    また一定時間毎に自動で保存する機能もあります。　 ホットキー:Shift + Ctrl + S

    詳細な設定についてはこちら

    ウィンドウサイズ調整

    チャート情報

    通貨ペア | 時間軸

    チャートの右上に現在の通貨ペアや時間軸の情報を表示
    通貨ペアのみ、時間軸のみの表示も可能です。

    スプレッド警告

    現在のスプレッドを常時表示し、設定した値以上になると色で警告を表示します。
    安全管理の一助となる機能です。

    ホットキー

    VergeRunnerで設定されているホットキーについてはこちら

    選択中のオブジェクトをすべて解除

    ホットキー: Ctrl + Shift + D

    GUIの位置をリセット

    GUIを初期位置に戻します。

    ホットキー: Ctrl + Shift + R

    時間軸の切り替え

    ホットキー: Q: 時間軸を下げる
    ホットキー: W: 時間軸を上げる

    チャートの自動スクロールの切り替え

    ホットキー: Z

    チャートのスケールロック

    ホットキー: X
